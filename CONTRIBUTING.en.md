# Contributing to Constellation

Thank you for wanting to help. Constellation's source code is not public: this repository holds the documentation and the released versions. Code pull requests are therefore not possible, but there are several ways to contribute.

## Report a bug

Open an issue with the **Report a bug** form. The more precise the report, the faster the fix:

- the Constellation version (Settings › About) and the macOS version;
- the steps to reproduce the problem;
- what you expected, and what happened;
- a screenshot or error message, with no personal information (paths, addresses, tokens);
- if possible, the diagnostic created by the **Help › Export Diagnostic…** menu (nothing is sent automatically, read it before attaching it).

Before opening an issue, have a look at the [Troubleshooting](README.en.md#troubleshooting) section of the README and at existing issues.

## Suggest an idea

Use the **Suggest an idea** form. Describe the need first, then the solution you imagine: a well-explained need can lead to a better solution than the one first proposed.

## Improve the documentation

An error or an unclear passage in the README? Open an issue with the **documentation** label, quoting the passage concerned.

## Security

A vulnerability is never reported in a public issue. Follow the [security policy](SECURITY.en.md).

## Good conduct

Stay courteous and constructive. Insulting, discriminatory or off-topic messages are hidden, and their authors may be blocked.
