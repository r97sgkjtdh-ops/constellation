# Contribuer à Constellation

Merci de vouloir aider. Le code source de Constellation n'est pas public : ce dépôt contient la documentation et les versions publiées. Les pull requests de code ne sont donc pas possibles, mais il y a plusieurs façons de contribuer.

## Signaler un bug

Ouvre une issue avec le formulaire **Signaler un bug**. Plus le signalement est précis, plus la correction est rapide :

- la version de Constellation (Réglages › À propos) et celle de macOS ;
- les étapes pour reproduire le problème ;
- ce que tu attendais, et ce qui s'est passé ;
- une capture ou un message d'erreur, sans information personnelle (chemins, adresses, jetons).

Avant d'ouvrir une issue, jette un œil à la section [Dépannage](README.md#dépannage) du README et aux issues existantes.

## Proposer une idée

Utilise le formulaire **Proposer une idée**. Décris d'abord le besoin, puis la solution que tu imagines : un besoin bien expliqué peut mener à une meilleure solution que celle proposée au départ.

## Améliorer la documentation

Une erreur ou un passage peu clair dans le README ? Ouvre une issue avec l'étiquette **documentation**, en citant le passage concerné.

## Sécurité

Une faille ne se signale jamais dans une issue publique. Suis la [politique de sécurité](SECURITY.md).

## Bonne conduite

Reste courtois et constructif. Les messages insultants, discriminants ou hors sujet sont masqués, et leurs auteurs peuvent être bloqués.
