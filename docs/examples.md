# Examples ready to copy

*[Version française](exemples.md)*

Type them in the command bar (⌘K). The names (`Claude 1`, `Team A`…) are those of your board. The board commands (7, 8, 10) are recognised in French.

1. **One instruction to one console**
   `Claude 1, run the tests and fix what fails`

2. **The same text to a whole group**
   `@Review tous : review the last commit and list the problems, without changing anything`

3. **Splitting a feature**
   `Add the dashboard's CSV export: the code, the tests and the documentation`
   The planner proposes one step per console; read the plan, change it if needed, then send it.

4. **Two teams, then a common report** (“Deux équipes” layout)
   `Team A audits security, team B performance, then one console writes the common final report`
   The final step waits for both teams and receives their reports.

5. **Write, then have it reviewed**
   `Claude 1 writes the payment module, then Claude 2 reviews what it wrote`
   In the plan, Claude 2's step shows “After Claude 1”; otherwise, pick it in its menu.

6. **Several review angles** (“Review Panel” layout)
   `Review the current branch: one security angle, one readability angle, one tests angle`

7. **Creating consoles**
   `crée 3 agents Claude`

8. **Handing over to another CLI**
   Select the console, then: `passe cette tâche à codex`

9. **Research, then synthesis** (“Recherche” layout)
   `Compare three chart libraries for our app, then write a synthesis with a recommendation`

10. **Switching workspace**
    `ouvre l'espace 2`
