# Exemples prêts à copier

*[English version](examples.md)*

Tape-les dans la barre de commande (⌘K). Les noms (`Claude 1`, `Équipe A`…) sont ceux de ton tableau.

1. **Une consigne à une console**
   `Claude 1, lance les tests et corrige ce qui échoue`

2. **Le même texte à tout un groupe**
   `@Revue tous : relis le dernier commit et liste les problèmes, sans rien modifier`

3. **Répartir une fonctionnalité**
   `Ajoute l'export CSV du tableau de bord : le code, les tests et la documentation`
   Le planificateur propose une étape par console ; relis le plan, modifie-le si besoin, puis envoie-le.

4. **Deux équipes, puis un compte rendu commun** (disposition « Deux équipes »)
   `L'équipe A audite la sécurité, l'équipe B les performances, puis une console fait le compte rendu final commun`
   L'étape finale attend les deux équipes et reçoit leurs comptes rendus.

5. **Écrire puis faire relire**
   `Claude 1 écrit le module de paiement, puis Claude 2 relit ce qu'il a écrit`
   Dans le plan, l'étape de Claude 2 affiche « Après Claude 1 » ; sinon, choisis-le dans son menu.

6. **Plusieurs angles de revue** (disposition « Review Panel »)
   `Relisez la branche courante : un angle sécurité, un angle lisibilité, un angle tests`

7. **Créer des consoles**
   `crée 3 agents Claude`

8. **Passer la main à un autre CLI**
   Sélectionne la console, puis : `passe cette tâche à codex`

9. **Recherche puis synthèse** (disposition « Recherche »)
   `Compare trois bibliothèques de graphiques pour notre app, puis fais une synthèse avec une recommandation`

10. **Changer d'espace**
    `ouvre l'espace 2`
